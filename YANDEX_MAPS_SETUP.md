# Настройка Яндекс.Карт API

## Для заказчика

Для работы карты на сайте необходимо получить API ключ от Яндекс.Карт.

### Шаги для получения ключа:

1. **Перейдите на сайт разработчика Яндекса:**

    - https://developer.tech.yandex.ru/

2. **Войдите в свой аккаунт Яндекса**

3. **Подключите API:**

    - Нажмите кнопку "Подключить API"
    - Выберите **"JavaScript API и HTTP Геокодер"**
    - Нажмите "Продолжить"

4. **Заполните форму:**

    - Укажите необходимые данные (ФИО, email, телефон)
    - Выберите юридический статус
    - Укажите цель использования: "Интернет-магазин"
    - Подтвердите согласие с условиями использования
    - Нажмите "Продолжить"

5. **Получите ключ:**

    - После регистрации вы получите API-ключ
    - Скопируйте его

6. **Передайте ключ разработчику:**
    - Отправьте ключ безопасным способом (не в открытом чате/email)
    - Рекомендуется использовать защищенный канал связи

### Ограничения по домену (рекомендуется):

В настройках ключа в Кабинете разработчика можно ограничить использование API-ключа только вашим доменом для повышения безопасности.

### Важно:

-   API ключ бесплатный для базового использования
-   После получения ключа может потребоваться до 15 минут для его активации
-   Ключ привязан к вашему аккаунту Яндекса

## Для разработчика

После получения ключа от заказчика:

1. Создайте файл `.env.local` в корне проекта (если его нет)
2. Добавьте строку:
    ```
    NEXT_PUBLIC_YANDEX_MAPS_API_KEY=полученный_ключ_от_заказчика
    ```
3. Перезапустите сервер разработки: `npm run dev`

### При деплое на продакшен:

Добавьте переменную окружения `NEXT_PUBLIC_YANDEX_MAPS_API_KEY` в настройках вашего хостинга:

-   **Vercel**: Settings → Environment Variables
-   **Netlify**: Site settings → Build & deploy → Environment variables
-   **Другие платформы**: согласно их документации

### Безопасность:

-   ✅ Файл `.env.local` уже в `.gitignore` - ключ не попадет в репозиторий
-   ✅ Не коммитьте `.env.local` в git
-   ✅ Не передавайте ключ в открытом виде
