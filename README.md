# ZNVES - Интернет магазин

SPA приложение для интернет-магазина одежды, созданное на React + Vite с использованием CSS Modules.

## Технологии

-   React 18
-   Vite
-   CSS Modules

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Настройка Яндекс.Карт

Для работы карты на странице оформления заказа необходимо настроить API ключ. Подробная инструкция в файле [YANDEX_MAPS_SETUP.md](./YANDEX_MAPS_SETUP.md).

**Кратко:**

1. Заказчик получает API ключ на https://developer.tech.yandex.ru/
2. Создайте файл `.env.local` с переменной `NEXT_PUBLIC_YANDEX_MAPS_API_KEY`
3. Карта работает и без ключа, но с предупреждением в консоли

## Структура компонентов

-   **Header** - Шапка сайта с бургер-меню, корзиной и личным кабинетом
-   **HeroSection** - Главный баннер с кнопкой "CATALOG +"
-   **ProductDisplaySection** - Переиспользуемый компонент для секций "NEW IN" и "CATALOG"
-   **ProductCard** - Карточка товара (title, price, image)
-   **Footer** - Подвал с навигацией и подпиской на рассылку
-   **Map** - Компонент Яндекс.Карт для выбора адреса доставки
