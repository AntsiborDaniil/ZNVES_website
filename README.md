# ZNVES - Интернет магазин

SPA приложение для интернет-магазина одежды, созданное на React + Vite с использованием CSS Modules.

## Технологии

-   React 18
-   Vite
-   CSS Modules

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Структура компонентов

-   **Header** - Шапка сайта с бургер-меню, корзиной и личным кабинетом
-   **HeroSection** - Главный баннер с кнопкой "CATALOG +"
-   **ProductDisplaySection** - Переиспользуемый компонент для секций "NEW IN" и "CATALOG"
-   **ProductCard** - Карточка товара (title, price, image)
-   **Footer** - Подвал с навигацией и подпиской на рассылку
