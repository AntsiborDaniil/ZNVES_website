# Что нужно от заказчика, чтобы работал виджет доставки (ПВЗ)

На сайте стоит виджет выбора пунктов выдачи и расчёта сроков/стоимости доставки. Он подключается через скрипт **ndd-widget.landpro.site** и обращается к API доставки. Сейчас расчёт не выполняется, потому что в настройках указана **отключённая станция** (точка отгрузки). Ниже — что именно нужно получить от заказчика и как это оформить.

---

## 1. Что нужно в первую очередь

### ID активной станции (source_platform_station)

Для расчёта сроков и стоимости доставки виджету нужен **идентификатор станции** — точки, откуда отправляются заказы (склад/магазин в системе доставки). Этот ID передаётся в API; если станция отключена или ID неверный, приходит ошибка **«source station is disabled»** и пользователь видит: *«Не удалось рассчитать сроки и стоимость»*.

**Нужно от заказчика:**

- **Один рабочий UUID станции** (формат: `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`), соответствующей **включённой** точке отгрузки в кабинете Яндекс.Доставки / Landpro (или у того, кто им поставляет виджет).

Без этого виджет физически не сможет рассчитать маршруты и цены.

---

## 2. Где это взять (план для заказчика)

Виджет: **[https://ndd-widget.landpro.site/](https://ndd-widget.landpro.site/)** (демо и, по сути, тот же скрипт, что на сайте).

ID станции берётся не из нашего кода, а из кабинета той системы, которая отдаёт виджет и держит API доставки. Обычно это:

- **Личный кабинет Яндекс.Доставки** (или партнёрский кабинет, через который заказчик подключён к доставке),  
  или  
- **Кабинет/панель Landpro** (если виджет и настройки доставки идут через них).

**Пошагово заказчику:**

1. **Зайти в кабинет**, где настроена доставка и откуда взят виджет (Яндекс.Доставка или Landpro / интегратор).
2. **Найти раздел про станции / точки отгрузки / склады** (названия могут быть: «Станции», «Точки отгрузки», «Склады», «Platform stations» и т.п.).
3. **Выбрать ту станцию**, с которой реально будут отправляться заказы, и убедиться, что она **включена** (активна).
4. **Скопировать ID (UUID) этой станции** и передать его вам (разработчику/менеджеру) в безопасном канале (не в открытом чате, если там есть посторонние).
5. Если в кабинете нет явного «ID станции» — **написать в поддержку** того сервиса (Яндекс.Доставка / Landpro), запросить: «ID активной станции (source_platform_station) для интеграции виджета на сайте».

Полезные ссылки:

- Демо виджета: [https://ndd-widget.landpro.site/](https://ndd-widget.landpro.site/)
- Документация и API Яндекс.Доставки: [https://yandex.ru/support/delivery-profile/](https://yandex.ru/support/delivery-profile/) (разделы по API и интеграции)
- При использовании Landpro — уточнить у них кабинет и раздел, где отображается ID станции.

---

## 3. Что сделать после получения ID

1. Заказчик передаёт вам **одну строку** — UUID активной станции (например: `a1b2c3d4-e5f6-7890-abcd-ef1234567890`).
2. Вы добавляете её в переменные окружения проекта:
   - в **`.env.local`** для локальной разработки;
   - в настройках **хостинга** (Vercel / и т.д.) для продакшена.
3. Имя переменной:
   ```env
   NEXT_PUBLIC_YA_DELIVERY_STATION_ID=uuid_который_прислал_заказчик
   ```
4. Перезапускаете приложение (dev-сервер или деплой). Виджет начнёт подставлять этот ID в запросы; если станция активна, расчёт сроков и стоимости должен заработать.

---

## 4. Краткий чек-лист для заказчика

- [ ] Зайти в кабинет (Яндекс.Доставка / Landpro или тот, откуда виджет).
- [ ] Найти раздел со станциями (точками отгрузки).
- [ ] Выбрать **включённую** станцию и скопировать её **ID (UUID)**.
- [ ] Если ID не виден — запросить в поддержке сервиса: «Нужен ID активной станции (source_platform_station) для виджета на сайте».
- [ ] Передать ID разработчику в безопасном виде.
- [ ] После подстановки в проект — проверить на сайте выбор ПВЗ и появление сроков/стоимости.

---

## 5. Опционально: карта и подсказки адресов

Для **карты курьерской доставки** и **подсказок адресов** в проекте также используется ключ Яндекс.Карт. Его получение и настройка описаны в **[YANDEX_MAPS_SETUP.md](./YANDEX_MAPS_SETUP.md)**. Если заказчик ещё не передавал ключ — его тоже нужно запросить по инструкции из этого файла.

---

Итого: чтобы виджет доставки работал, заказчику нужно получить **один активный ID станции** из кабинета доставки и передать его вам для подстановки в `NEXT_PUBLIC_YA_DELIVERY_STATION_ID`.
